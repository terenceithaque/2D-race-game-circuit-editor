This software is a small editor designed to allow the creation of simple 2D circuits for racing games.
It mainly uses PyQt6, which is a modern GUI API for applications written in Python.

The software is composed of several files and folders with distinct roles:

    - main.py: defines the main window and runs the application.
    - special_popups: contains several scripts defining popups used by the application.$
    - user_data: contains several scripts handling user-related data (such as circuit files, etc).
    - editor_widgets: contains several scripts used by the circuit editor for specific widgets.
